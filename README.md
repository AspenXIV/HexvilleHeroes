# Hexville Heroes

**Status:** School project – kinda scuffed, but it works! 🎮

---

## 📖 About
Hexville Heroes was a project I created for school, as a group project.  
It’s **not perfect** (in fact, it's *hella scuffed*), but the main goal was to get something working and it **does** work!

This project was a great learning experience, even if the codebase is a little messy and the design isn’t AA quality.  
Think of it as a **proof of concept** rather than a polished final game.

---

## ✨ Features
- Functional core gameplay loop
- Various systems implemented under tight deadlines
- Built with **Unity** using **C#**, ShaderLab, and HLSL
- Hundreds of commits showing a chaotic but determined development process 💀
